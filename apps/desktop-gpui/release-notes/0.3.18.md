## 中文

- 首页顶栏新增导入视频入口，点「最近录制」左边的图标，就能选择视频并打开编辑器。空素材库也可以直接导入。
- 在同一项目里追加录制时，开启自动字幕和工作流翻译后，新片段会自动生成字幕，并译成预设语言。已有字幕和手工译文会保留。
- 长录屏的时间线可以缩到全片，首尾一起可见。右下角缩略导航条更容易拖动。

## English

- Import an existing video from the icon beside Recent Recordings. The editor opens when the import finishes, and empty libraries also offer import actions.
- When automatic captions and workflow translation are enabled, recordings appended to a project get captions in the configured language. Existing captions and manually edited translations are preserved.
- Fit long recordings end to end on the timeline and navigate them with a larger minimap.
