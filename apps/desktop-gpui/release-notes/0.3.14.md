## 关键帧

- 文字、形状和遮罩也可以添加关键帧。文字字号、遮罩强度和音乐音量可以随时间变化。
- 在时间线上选中、拖动或删除关键帧。拖动播放头时可以吸附到关键帧，支持动画的滑块旁也能直接添加关键帧。

## Windows 开发环境

- 缺少 Visual Studio LLVM 组件时，构建脚本可下载并校验备用 libclang。直接运行开发构建时，桌面应用可以在对应目录找到所需的 DLL。

## Keyframes

- Add keyframes to text, shapes, and masks. Animate text size, mask strength, and music volume over time.
- Select, drag, or delete keyframes on the timeline. Snap the playhead to a keyframe or add one from the diamond next to an animatable slider.

## Windows development setup

- The build setup can download and verify a fallback libclang when Visual Studio LLVM is missing. Desktop development builds receive their runtime DLLs in the corresponding output directories.
