## 中文

- 「内置配乐」新增四首 CC0 曲目，涵盖氛围电子、轻钢琴、轻爵士和慢拍电子。可以直接试听并加入时间线。
- 简化「重新生成字幕」面板。模型和重做范围集中显示，生成中可以收起面板，回来继续试听预览。
- 可以在字幕面板直接选择已配置的豆包等云端识别模型，也可以跳到对应的服务设置。

## English

- Added four CC0 tracks to the built-in music library, covering ambient electronic, soft piano, light jazz, and downtempo electronic. Preview any track and add it to the timeline.
- Simplified the caption regeneration panel. Choose the model and scope in one place, then close the panel during generation and return to audition the preview.
- Select a configured cloud recognizer such as Doubao directly in the captions panel, or open the settings for a provider.
