### 简体中文

- 修复 macOS 更新时旧进程仍在运行可能导致权限提示异常的问题。灵录先保存并退出，再安装更新。退出超时可继续使用当前版本，稍后重试。

### English

- Fixed a macOS update issue that could show unexpected permission warnings while the previous version was still running. Capwise saves and quits before installing the update. If quitting times out, you can keep using your current version and try again later.
