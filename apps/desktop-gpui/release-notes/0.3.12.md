## 字幕样式

- 新生成的字幕默认使用「通用录屏」，中英字体分别为 Noto Sans SC 和 Inter。
- 原有样式继续可选，新增「通用录屏」「科技教程」「纪录片」。三套新样式均为透明背景，搭配细描边。
- 已有项目保留保存的字幕样式。设为默认的自定义样式继续应用到新字幕。

## 豆包配音

- 音色选择新增「刘飞 2.0」「悠悠君子 2.0」「爽快思思 2.0」和「知性灿灿 2.0」，可在设置里直接试听。

## Caption styles

- New captions default to Screen Recording, which pairs Noto Sans SC with Inter.
- Screen Recording, Tech Tutorial, and Documentary join the existing choices. All three new styles use a transparent background and a fine outline.
- Existing projects retain their saved styles, and custom defaults still apply to new captions.


## Doubao narration

- Preview and choose four additional Mandarin voices in settings, including Liu Fei 2.0.
