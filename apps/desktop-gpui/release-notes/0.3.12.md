## 字幕样式

- 新生成的字幕默认使用「通用录屏」。中文使用 Noto Sans SC，英文译文使用 Inter，搭配细描边和半透明圆角底板。
- 样式选择新增「科技教程」和「纪录片」。科技教程采用画面边缘渐变，纪录片采用中英衬线字体。
- 已有项目保留保存的字幕样式。设为默认的自定义样式继续应用到新字幕。

## Caption styles

- New captions default to Screen Recording, which pairs Noto Sans SC with Inter, a thin outline, and a translucent rounded background.
- Choose Tech Tutorial for an edge gradient or Documentary for paired Chinese and English serif fonts.
- Existing projects retain their saved styles, and custom defaults still apply to new captions.
