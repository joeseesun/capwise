开始之前

你可能还想知道

这是免费的软件吗？

灵录免费开源。基础录制、编辑与本地导出不需要购买应用订阅。第三方 AI 服务可能按量计费，需要使用你自己的服务或账号。

支持哪些电脑？

当前提供 macOS 13.3 及以上的 Apple Silicon 安装包。Intel Mac、Windows、Linux 尚无本项目验证过的发布包，暂不建议按同样步骤安装。

不开通 AI 服务，可以用吗？

可以。录制、时间线编辑、画面美化、文字标注、配乐与本地导出都可以先用。AI 校对、翻译和封面生图需要配置相应模型；本地识别可能需要先下载模型文件。

AI 会直接替我修改整个视频吗？

字幕与编辑操作会先提出可审阅的修改方案，应用后可以撤销。生成封面会直接调用你配置的图片服务并应用结果，对话内可编辑、重做或撤销。AI 可能改错术语和语气，重要内容请在导出前检查。长字幕会分批处理，不等于一次请求检查了全片。

“删字幕”会不会把声音也删掉？

普通字幕修改只改变文字。明确进入“按文字剪辑视频”时，删除文字也会剪掉对应的音视频区间；AI 助手只有在你明确要求剪除语音或视频时才使用这类操作，请审阅时长变化。

视频和 API Key 会被上传吗？

项目和媒体保存在本机，macOS API Key 保存在登录钥匙串。云端识别会上传音频；文本 AI 使用相关字幕和编辑上下文；封面生图发送图片描述。你可以选择本地模型，或不启用云端 AI。

安装或使用遇到问题怎么办？

先确认系统与芯片符合要求，再查看 更新说明。也欢迎在 GitHub 报告问题，附上版本、系统和复现步骤，别上传密钥或私人录屏。
